# SPGD-site

Public site leaf for a spatial spot-composition object (openST, MERFISH, STARmap).

- Live: https://peterponyu.github.io/SPGD-site/
- Repository: https://github.com/PeterPonyu/SPGD-site
- Archive: https://doi.org/10.5281/zenodo.21869991

This repository is the Next.js static export. It is not a published article and has no article DOI. The Pages leaf has no figures and no numeric results.

```bash
NEXT_PUBLIC_BASE_PATH=/SPGD-site npm ci && npm run build && npm run verify
```
